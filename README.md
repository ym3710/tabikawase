# tabikawase（旅為替ナビ）

海外旅行者向けの為替情報サイト。現地での支払いが「今、何円になるか」を換算し、あわせて「今は両替のお得なタイミングか」の目安を表示する。

## できること

1. **現地価格 → 円換算**：通貨を選び、現地での支払額を入力すると、今日のレートで何円になるかを表示する。
2. **両替タイミングの目安**：直近90日間の平均レートと現在のレートを比較し、「円高寄り（買い時）」「平均的」「円安寄り（割高）」の3段階で表示する。
3. **90日間の推移グラフ**：Canvasで描画したシンプルな折れ線グラフで、直近90日のレートの動きと平均線を確認できる。

対応通貨は、日本人が旅行でよく利用する15通貨（米ドル、ユーロ、英ポンド、豪ドル、加ドル、スイスフラン、NZドル、韓国ウォン、香港ドル、シンガポールドル、タイバーツ、マレーシアリンギット、フィリピンペソ、インドネシアルピア、中国人民元）に絞っている。

なお台湾ドル（TWD）とベトナムドン（VND）は人気の旅行先通貨だが、ECB参考レートの対象通貨に含まれていないため、データソースの信頼性を優先し今回は対象外とした。

## データ出典について

為替レートは **欧州中央銀行（ECB: European Central Bank）が公表する外国為替参考レート** を、[Frankfurter API](https://frankfurter.dev/) 経由で取得している。

- ECBは為替の当事者ではなく中央銀行という公的機関であり、参考レートは平日1回、決まった時刻に公表される、透明性のあるデータである。
- Frankfurter APIはこのECB公式データをそのまま配信するAPIで、APIキー登録不要・CORS対応済みのため、静的サイトからも直接呼び出せる。
- Yahoo!ファイナンスのスクレイピングや、民間の为替まとめサイトなど「誰でも書き換えられる／出典が不透明な」情報源は使っていない。

ただし、ECB参考レートは**1日1回更新**であり、秒単位のリアルタイム相場ではない。また実際の両替・カード決済では、金融機関ごとの手数料（スプレッド）が別途上乗せされるため、本サイトの数字はあくまで目安である。この点はサイト本文にも明記している。

## 両替タイミングの判定ロジック

- 直近90日分の「1単位の外貨 = 何円か」のレート列を取得し、単純平均を算出する。
- 現在レートが平均より **1.5%以上低い**（＝同じ外貨を今の方が少ない円で買える＝円高寄り）→「買い時」寄りと表示。
- 現在レートが平均より **1.5%以上高い**（＝円安寄り）→「割高」寄りと表示。
- 差が ±1.5% 未満なら「平均的な水準」と表示。

将来のレートを予測するものではなく、あくまで直近の実績との比較であることをUI上でも明記している。

## 使用技術

- HTML / CSS / JavaScript（フレームワークなし、素の実装）
- [Frankfurter API](https://frankfurter.dev/)（ECB公式為替データ、APIキー不要）
- Canvas API（グラフ描画、外部グラフライブラリ不使用）
- GitHub Pages（静的サイトホスティング想定）

## ローカルでの確認方法

```bash
npx serve .
```

でこのディレクトリを配信し、表示されたURLをブラウザで開く。APIキーの設定は不要。
